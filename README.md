# Sumaya Akter - Portfolio Website

A modern, fully responsive personal portfolio website built with **Next.js**, **TypeScript**, and **Tailwind CSS**.

## 🚀 Live Demo

https://sumaya-akter-portfolio.vercel.app/

## ✨ Features
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **Hero Section:** Introduction with social links and resume download button.
- **About Me:** Detailed journey and quick overview cards.
- **Skills:** Graphical representation of technical skills.
- **Projects:** Dynamic project cards with detailed pages including challenges and future plans.
- **Contact:** Functional form with contact info.

## 🛠️ Technologies Used
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Deployment:** Vercel
